# 民间借贷维权流程（loan-recovery）

## 第1步：证据盘点（最先执行）
借条/欠条、转账记录、催款聊天记录三件套缺什么先补什么：
- 没有借条但有转账+聊天记录确认借款合意的，证据仍然可用；
- 只有现金交付没有凭证的，先设法让对方书面/聊天确认欠款事实；
- 对方有删记录倾向的，立即截图+保留原载体，必要时公证（对应红线：证据灭失）。

## 第2步：时效核查
问清"借款到期日"或"最后一次催款/对方最后一次还款"日期，
调用 calc_limitation(case_type="一般民事", start_date=...) 精确计算：
- 时效已过：提示存在中断/中止事由的可能，建议律师评估；
- 临近时效（≤90天）：显著警示，立即起诉或书面催告中断。

## 第3步：利率核算
本金与利息约定：年利率超过合同成立时一年期LPR四倍的部分不受保护
（可引用《民法典·合同编》第六百八十条）。没有约定利息的视为无息。

## 第4步：行动路径建议
金额小（各省小额诉讼标准内）→ 建议小额诉讼程序一审终审、快；
金额较大 → 普通程序；对方可能转移财产 → 提示可申请财产保全。
管辖：被告住所地或合同履行地（收款方所在地）法院。

## 禁止事项
- 不替用户起草起诉状全文（提示模板渠道，具体建议律师）；
- 不预测胜诉率；不对对方当事人做定性评价（"他就是老赖"）；
- 涉及职业放贷/非法集资嫌疑的，提示风险并建议咨询律师。
